# AntiSpam для ВКонтакте

Расширение для Chrome и Brave, которое ищет рекламные диалоги и давно неактивные переписки в веб-версии ВК. Поиск выполняется в открытой вкладке. Очистка истории запускается после просмотра списка и подтверждения.

[Скачать последнюю версию 0.8.5](releases/antispam-vk-0.8.5.zip) · [Все версии и изменения](CHANGELOG.md)

## Установка

1. Скачайте и распакуйте ZIP.
2. Откройте `chrome://extensions` в Chrome или `brave://extensions` в Brave.
3. Включите режим разработчика и нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку с файлом `manifest.json`.

Для обновления замените файлы в папке расширения, нажмите кнопку перезагрузки на его карточке и обновите вкладку ВК.

## Использование

1. Откройте сообщения ВКонтакте и нажмите значок AntiSpam.
2. Выберите поиск спама, отбор по сроку неактивности или оба условия. Укажите типы диалогов и срок в сутках.
3. Нажмите **«Проверить диалоги»** и просмотрите список кандидатов.
4. Подтвердите очистку, только если готовы удалить историю во всех предложенных диалогах. Если ВК требует наведения, оставьте курсор над кнопкой **⋯** в шапке открытого чата. Кнопка **«Стоп»** прекращает дальнейшие попытки очистки.

AntiSpam работает с интерфейсом ВК, поэтому изменения в нём могут нарушить распознавание меню или подтверждения. Боты без явной метки ВК могут отображаться как сообщества. Кнопки **«Скачать отчёт»** и **«Скопировать отчёт»** экспортируют диагностические этапы и счётчики без имён, идентификаторов и текста переписок. Экспортируйте отчёт до следующего запуска проверки.
